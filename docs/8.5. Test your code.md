# 8.5 Test your code

## Task List

Here are the steps to test the `Driver` class:

- [ ] Create a Java class and name it `Driver` or `Tester`.
- [ ] Include a main method:
  `public static void main(String[] args) {}`
- [ ] Add:
  `Customer customer = new Customer("first", "second", "j@domain.com");`
- [ ] Next line add `System.out.println(customer);`
  Note: If you have overridden the `toString()` method for the `Customer` class, this line will display the class contents.

## Task List

Let's use this technique to test your email validation:

- [ ] Add:
  `Customer customer = new Customer("first", "second", "email");`
- [ ] Run the driver program by right-clicking and selecting **Run**.
- [ ] An `IllegalArgumentException` should be thrown because the string `email` does not match our regular expression format for email (`name@domain.com`).
